# FOSSIL HUNTERS — 化石発掘 & 恐竜バトル

アイソメトリック・ボクセル調のグラフィックスデモ（Three.js / ブラウザ）。
雨上がりの発掘場を舞台に、化石を掘り、祭壇で恐竜を復活させ、野生の魔獣と戦う。

## 遊び方

```sh
python3 -m http.server 8099
# → http://127.0.0.1:8099/index.html
```

| 操作 | 動作 |
|---|---|
| クリック | 移動 / 発掘地点（赤い旗）をクリックで採掘 |
| ドラッグ | カメラ回転 |
| スクロール | ズームイン / アウト |
| SPACE | 祭壇の近くで恐竜を復活 |
| F | 復活させた恐竜に攻撃指示 |

## 単一ファイル版のビルド

```sh
node tools/bundle.mjs dist.html   # three.js とすべてのモジュールを 1 つの HTML に同梱
```

## 技術メモ

- **アセットのダウンロードなし。** 形状はすべてコード内のボクセルビルダーで生成し、
  1 つのマージ済みジオメトリに統合している（静的ワールドは実質 1 ドローコール）。
- **反射する濡れた床**（`src/ground.js`）: 鏡像カメラによる実際の平面反射を
  半解像度 RT にレンダリングし、斜め near クリップで床下の漏れを除去。
  水たまりマスクで「鏡面（水たまり）／ぼやけた光沢（湿り）／マット（乾き）」を切り替え、
  雨の波紋が法線と反射 UV を歪ませる。
- **ボクセルなのに PBR**（`src/voxel.js`）: 頂点属性で粗さ・金属度・自己発光を持たせ、
  `MeshStandardMaterial` にパッチ。面ごとの陰影と 3D ノイズで平坦さを消している。
- **環境光**: 空シェーダー自体から PMREM を生成し IBL に使用。
- **キャラクター**: 階層リグ付きボクセル。歩行サイクル、呼吸、遅れて追従するマント、
  発掘・咆哮・攻撃・被弾モーション。
- **世界の気配**: 雨、水面の波紋、焚き火の残り火、蛍、漂う霧、コウモリ、
  ランタンの揺らぎ、結晶の脈動、遠景の巨大な竜の骨。
